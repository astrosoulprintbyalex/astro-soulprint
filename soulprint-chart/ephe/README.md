# Swiss Ephemeris data files

| File | Covers | Size |
|------|--------|------|
| `sepl_18.se1` | Sun, planets, Pluto, nodes (years 1800-2400) | 484 KB |
| `semo_18.se1` | Moon (years 1800-2400) | 1.3 MB |
| `seas_18.se1` | Asteroids: Chiron, Juno, Ceres, Pallas, Vesta, Pholus (years 1800-2400) | 223 KB |

These are the standard Swiss Ephemeris files by Astrodienst AG (https://www.astro.com/swisseph/), used under the GNU
AGPL-3.0. They were taken from the data bundle of the npm package `swisseph-wasm` 0.1.0. The official copies are at
https://github.com/aloistr/swisseph/tree/master/ephe : you can replace these three files with them at any time.

The page only downloads them when a visitor chooses the Birth Chart, and the birth form accepts years from 1900.
